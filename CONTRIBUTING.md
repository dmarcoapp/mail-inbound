# Contributing

This repository held the DMARCo inbound mail gateway: Postfix, the Node
processor, and the certificate automation. It is archived, and the gateway is
retired, so it takes no more pull requests. DMARCo now reads its reports from
mailboxes over IMAP, in [`dmarcoapp/backend`](https://github.com/dmarcoapp/backend).

**Issues belong in [`dmarcoapp/dmarcoapp`](https://github.com/dmarcoapp/dmarcoapp/issues),**
together with every other DMARCo issue, including problems with installs that
still run this gateway.

The contribution guide for the rest of DMARCo lives in the main repository:
[`CONTRIBUTING.md`](https://github.com/dmarcoapp/dmarcoapp/blob/main/CONTRIBUTING.md).
