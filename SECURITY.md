# Security Policy

Please do not report a vulnerability in a public issue or pull request.

DMARCo has one security policy for all of its components. Supported versions,
scope and what to include are documented in the main repository:
[`dmarcoapp/dmarcoapp/SECURITY.md`](https://github.com/dmarcoapp/dmarcoapp/blob/main/SECURITY.md).

Report privately here, whichever component the vulnerability is in:
[Report a vulnerability](https://github.com/dmarcoapp/dmarcoapp/security/advisories/new).
